<Aside type="tip" title="このガイドラインで目指すこと">
光感受性発作を引き起こす可能性のある閃光を避けることで、てんかんや光感受性発作の既往歴を持つユーザーが安全にコンテンツを利用できるようにします。

- すべてのユーザーが安全にコンテンツを閲覧できる
- 健康被害のリスクを最小限に抑える
</Aside>

## このガイドラインが達成されないとどうなるか

<Aside type="caution">
適切な対策がされていない閃光は、一部のユーザーにてんかん発作を引き起こし、重篤な健康被害を与える可能性があります。
</Aside>

結果的に、法的責任を問われる可能性もあり、サービスの信頼性を大きく損ないます。

<Card title="具体例：動画サイトでの危険" icon="information">
1997年、日本のテレビアニメ「ポケットモンスター」の一シーンで、
赤と青の激しい閃光が約4秒間続いた結果、
685人以上の子どもがてんかん様の発作を起こし、150人以上が入院しました。
これにより、閃光の危険性が広く認識されるようになりました。
</Card>

<Aside type="danger" title="こんなとき、達成されていないかもしれません">
- ローディングアニメーションが高速で点滅している
- スライドショーが瞬間的に切り替わる
- エラー時に画面全体が赤く点滅する
- 動画広告に激しいストロボ効果が含まれている
- ゲームのエフェクトで画面が激しく明滅する
</Aside>

## 最低限、すぐに取り組めること

### 要件定義

- アニメーションのガイドラインを定める
- 閃光効果を禁止するルールを明記する

### デザイン

- アニメーションは滑らかなトランジションを使用する
- 点滅ではなくフェード効果を使用する

### 開発

- CSSアニメーションの最小間隔を0.4秒以上に設定する
- `prefers-reduced-motion`に対応する

<Card title="最小限の実装例" icon="approve-check">

<LiveCodeExample
  html={dedent`
    <style>
      /* 動きを減らす設定への対応 */
      @media (prefers-reduced-motion: reduce) {
        * {
          animation-duration: 0.01ms !important;
          animation-iteration-count: 1 !important;
          transition-duration: 0.01ms !important;
        }
      }
      
      /* 安全なアニメーションの例 */
      @keyframes safe-animation {
        from { opacity: 0; }
        to { opacity: 1; }
      }
      
      .animated-element {
        animation: safe-animation 0.5s ease-in-out;
      }
    </style>
    
    <div class="animated-element">
      この要素は安全にアニメーションします
    </div>
  `}
  css={dedent`
    .animated-element {
      padding: 20px;
      background: #e3f2fd;
      border-radius: 8px;
      text-align: center;
    }
  `}
  client:load
/>

</Card>

### QA

- すべてのアニメーションをチェックする
- 1秒間に3回以上の変化がないか確認する
- `prefers-reduced-motion`の動作をテストする

### リリース後

- ユーザーからのフィードバックを収集する
- 新しいコンテンツ追加時にレビューを徹底する

## よくある問題と解決方法

### スライドショーの自動再生

```javascript title="安全なスライドショーの実装"
// 悪い例：瞬間的な切り替え
slider.style.transition = 'none';
slider.style.transform = `translateX(${position}px)`;

// 良い例：スムーズなトランジション
slider.style.transition = 'transform 0.5s ease-in-out';
slider.style.transform = `translateX(${position}px)`;
```

### アクセシビリティ設定の提供

```javascript title="ユーザー設定の実装例"
const userSettings = {
  reduceMotion: window.matchMedia('(prefers-reduced-motion: reduce)').matches,
  disableAnimations: false,
  autoplayVideos: false
};

// 設定に基づいてアニメーションを制御
if (userSettings.reduceMotion || userSettings.disableAnimations) {
  document.body.classList.add('no-animations');
}
```

## チェックリスト

### 必ず対応（高優先度）

<Aside type="caution" title="必須チェック項目">
- [ ] **1秒間に3回以上**の点滅がない
- [ ] **赤色の閃光**を避けている
- [ ] **画面の25%以上**の領域が点滅しない
</Aside>

<Aside type="note" title="推奨項目（中優先度）">
- [ ] **prefers-reduced-motion**に対応している
- [ ] **動画コンテンツ**に警告を表示している
- [ ] **アニメーションを無効化**するオプションがある
</Aside>

### 関連項目（別ガイドライン対象）

- [ ] **一時停止・停止・非表示**ができる（2.2.2）
- [ ] **アニメーション**が必須でない（2.3.3）

## 知っておくと便利なこと

### 安全な間隔の計算

| 間隔 | 頻度 | 安全性 |
|------|------|-------|
| 0.1秒 | 10回/秒 | 危険 |
| 0.33秒 | 3回/秒 | ギリギリ |
| 0.4秒以上 | 2.5回/秒以下 | 安全 |

<Aside type="tip" title="prefers-reduced-motionの活用">
ユーザーのOS設定を尊重することで、よりアクセシブルな体験を提供できます。

```css
/* 通常のアニメーション */
.element {
  animation: slide 1s ease-in-out;
}

/* 動きを減らす設定が有効な場合 */
@media (prefers-reduced-motion: reduce) {
  .element {
    animation: none;
  }
}
```
</Aside>

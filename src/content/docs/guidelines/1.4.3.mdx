<Aside type="tip" title="このガイドラインで目指すこと">
視覚的なコントラストを適切に確保することで、弱視や高齢者など、視力に制約のあるユーザーがテキストやUI要素を認識しやすくします。

- 様々な環境（明るい場所や古いディスプレイなど）でも読みやすい
- 視力に関わらず情報を確実に伝える
</Aside>

## このガイドラインが達成されないとどうなるか

<Aside type="caution">
コントラスト比が不足すると、弱視の方や高齢者がテキストを読めなくなり、重要な情報を見逃したり、サービスを利用できなくなります。
</Aside>

結果的に、多くのユーザーがサービスから排除され、ビジネス機会の損失にもつながります。

<Card title="具体例：Webサイトでの困りごと" icon="information">
Dさんは軽度の弱視があり、薄いグレーのテキストが白背景に配置されたサイトを閲覧していました。
重要な利用規約が読めず、知らずに規約違反をしてしまい、アカウントが停止されてしまいました。
十分なコントラストがあれば、このような問題は防げました。
</Card>

<Aside type="danger" title="こんなとき、達成されていないかもしれません">
- 薄いグレーのテキストを白背景で使用している
- プレースホルダーテキストが薄すぎる
- 無効化されたボタンのテキストが見えづらい
- リンクの色が背景と区別しづらい
- エラーメッセージが薄い赤色で表示されている
</Aside>

## 最低限、すぐに取り組めること

### 要件定義

- コントラスト比の基準をプロジェクトで統一する
- デザインシステムに最小コントラスト比を明記する

### デザイン

- カラーパレットを作成する際にコントラスト比を検証する
- テキストサイズごとの最小コントラスト比を定義する

### 開発

- CSS変数で色を管理し、一括変更できるようにする
- 開発者ツールでコントラスト比を確認する習慣をつける

<Card title="最小限の実装例" icon="approve-check">

<LiveCodeExample
  html={dedent`

## よくある問題と解決方法

### ブランドカラーがコントラスト比を満たさない場合

#### 段階的な改善アプローチ

1. **テキスト以外での使用**：ブランドカラーは装飾的な要素に限定
2. **色の調整**：明度を調整した派生色を作成
3. **サイズで対応**：大きなテキスト（24px以上）で使用

```css title="ブランドカラーの調整例"
:root {
  /* オリジナルのブランドカラー */
  --brand-original: #80b3ff;
  
  /* テキスト用に調整した色 */
  --brand-text: #0052cc;      /* 明度を下げて4.5:1を確保 */
  --brand-text-large: #4d94ff; /* 大きなテキスト用（3:1）*/
}
```

### グラデーション背景での対応

## チェックリスト

### 必ず対応（高優先度）

<Aside type="caution" title="必須チェック項目">
- [ ] **通常テキスト**（18px未満）が4.5:1以上
- [ ] **大きなテキスト**（24px以上、18px以上の太字）が3:1以上
- [ ] **リンクテキスト**が周囲のテキストと区別できる
</Aside>

<Aside type="note" title="推奨項目（中優先度）">
- [ ] **プレースホルダー**が4.5:1以上
- [ ] **フォーカス表示**が3:1以上
- [ ] **エラーメッセージ**が4.5:1以上
</Aside>

### 関連項目（別ガイドライン対象）

- [ ] **非テキストコンテンツ**のコントラスト（1.4.11）
- [ ] **色の使用**による情報伝達（1.4.1）

## 知っておくと便利なこと

### コントラスト比の基準

| テキストサイズ | 最小コントラスト比 | AAA基準 |
|--------------|------------------|--------|
| 通常（18px未満） | 4.5:1 | 7:1 |
| 大きい（24px以上） | 3:1 | 4.5:1 |
| 太字（18px以上） | 3:1 | 4.5:1 |

<Aside type="tip" title="開発者ツールでの確認方法">
Chrome DevToolsでは、要素を選択すると自動的にコントラスト比が表示されます。

1. 要素を右クリック → 「検証」
2. Stylesパネルで色のプレビューをクリック
3. コントラスト比と合格/不合格が表示される
</Aside>

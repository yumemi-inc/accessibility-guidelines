<Aside type="tip" title="このガイドラインで目指すこと">
見出しとラベルがコンテンツの目的を明確に伝えることで、ユーザーが情報を効率的に理解し、必要な情報へ素早くアクセスできるようにします。

- スクリーンリーダーユーザーがページ構造を把握できる
- 認知的な負荷を軽減し、必要な情報を素早く見つけられる
</Aside>

## このガイドラインが達成されないとどうなるか

<Aside type="caution">
見出しやラベルが不明確だと、ユーザーはコンテンツの内容を理解するのに時間がかかり、必要な情報を見つけられない可能性があります。
</Aside>

結果的に、特にスクリーンリーダーを使用するユーザーは、ページ全体を読まなければ内容を把握できず、非常に非効率になります。

<Card title="具体例：設定画面での困りごと" icon="information">
Fさんはスクリーンリーダーを使用しています。
あるアプリの設定画面で、「設定1」「設定2」「設定3」という見出しが使われていました。
各設定が何を意味するのか分からず、すべてのセクションを読み上げて確認する必要がありました。
</Card>

<Aside type="danger" title="こんなとき、達成されていないかもしれません">
- 見出しが「セクション1」「項目A」など、内容を説明していない
- フォームのラベルが「入力欄」「テキスト」など曖昧
- ボタンが「こちら」「クリック」など目的が不明
- 見出しの階層構造が論理的でない（h1の次にh4があるなど）
- 同じページに同じ見出しが複数ある
</Aside>

## 最低限、すぐに取り組めること

### 要件定義

- 見出しとラベルのガイドラインを定義する
- 見出しはコンテンツの内容を説明する具体的な文言にする

### デザイン

- 見出しの階層構造を視覚的に設計する
- フォームのラベルは入力内容を明確に示す
- ボタンは動作を説明するラベルにする

### 開発

- 見出しは論理的な階層構造（h1→h2→h3）を維持する
- フォームの`label`要素と`input`を`for`属性で関連付ける
- ボタンには動作を説明するテキストを含める

```html title="適切な見出し構造の例"
<h1>商品カタログ</h1>
  <h2>電化製品</h2>
    <h3>テレビ</h3>
    <h3>オーディオ</h3>
  <h2>家具</h2>
    <h3>ソファ</h3>
    <h3>テーブル</h3>
```

### QA

- スクリーンリーダーで見出しの一覧を確認する
- 見出しだけでページの内容が理解できるか確認する
- フォームのラベルが入力内容を適切に説明しているか確認する

### リリース後

- ユーザーからのフィードバックを収集する
- 分かりにくい見出しやラベルを改善する

## よくある問題と解決方法

### 見出しの階層構造が崩れている

<Aside type="danger">
見出しレベルをスキップすると、スクリーンリーダーユーザーは構造を理解しにくくなります。
</Aside>

```html title="悪い例：見出しレベルのスキップ"
<h1>ページタイトル</h1>
<h4>セクション1</h4> <!-- h2, h3をスキップ -->
<h2>セクション2</h2>
```

```html title="良い例：論理的な階層構造"
<h1>ページタイトル</h1>
<h2>セクション1</h2>
<h3>サブセクション1-1</h3>
<h2>セクション2</h2>
```

### 「こちら」「クリック」などの曖昧なリンク

リンクテキストは、リンク先の内容が分かるようにする必要があります。

```html title="悪い例"
<p>詳細は<a href="/guide">こちら</a>をご覧ください。</p>
```

```html title="良い例"
<p><a href="/guide">利用ガイド</a>をご覧ください。</p>
<!-- または -->
<p>詳細は<a href="/guide">利用ガイドのページ</a>をご覧ください。</p>
```

### 同じラベルが複数ある

同じページに同じラベルのボタンが複数あると、どれを押すべきか分かりません。

## チェックリスト

<Aside type="caution" title="必須チェック項目">
- [ ] 見出しがコンテンツの内容を正確に説明している
- [ ] 見出しの階層構造が論理的である（h1→h2→h3の順）
- [ ] フォームのラベルが入力内容を明確に示している
- [ ] ボタンやリンクのテキストが目的を説明している
</Aside>

<Aside type="note" title="推奨項目（中優先度）">
- [ ] 見出しだけでページの概要が理解できる
- [ ] 同じページに同じ見出しが重複していない
- [ ] 「こちら」「クリック」などの曖昧なリンクテキストがない
</Aside>

## 知っておくと便利なこと

### スクリーンリーダーでの見出しナビゲーション

スクリーンリーダーは見出しの一覧を表示する機能があります。ユーザーは見出し間をジャンプしてページを素早く把握できます。

| キー | 動作（NVDA/JAWS） |
|-----|------------------|
| H | 次の見出しへ移動 |
| Shift + H | 前の見出しへ移動 |
| 1〜6 | 指定レベルの見出しへ移動 |

### aria-label と aria-labelledby

視覚的なラベルを変更せずに、スクリーンリーダー向けに説明を追加できます。

```html title="aria-labelの使用例"
<!-- アイコンのみのボタン -->
<button aria-label="メニューを開く">
  <svg>...</svg>
</button>

<!-- 複数の同名ボタンを区別 -->
<button aria-label="商品Aを削除">削除</button>
<button aria-label="商品Bを削除">削除</button>
```

```html title="aria-labelledbyの使用例"
<section aria-labelledby="section-title">
  <h2 id="section-title">お知らせ</h2>
  <p>内容...</p>
</section>
```

### 見出しレベルの選び方

| 見出しレベル | 用途 |
|------------|------|
| h1 | ページのメインタイトル（通常1つ） |
| h2 | 主要なセクション |
| h3 | h2内のサブセクション |
| h4〜h6 | さらに細かい階層 |

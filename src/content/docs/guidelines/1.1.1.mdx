<Aside type="tip" title="このガイドラインで目指すこと">
視覚的な情報に依存できないユーザー（スクリーンリーダー利用者など）が、画像やアイコンなどの非テキストコンテンツの内容や目的を理解できるようにします。

- すべてのユーザーが同等の情報へアクセスできる
- 視覚に依存しない形で情報を伝達できる
</Aside>

## このガイドラインが達成されないとどうなるか

<Aside type="caution">
代替テキストがないと、スクリーンリーダーは画像のファイル名を読み上げたり、何も読み上げなかったりするため、ユーザーは重要な情報を得られません。
</Aside>

結果的に、視覚に依存できないユーザーは、ページの内容を正しく理解できず、誤った操作をしてしまう可能性があります。

<Card title="具体例：ECサイトでの困りごと" icon="information">
Bさんはスクリーンリーダーを使用してオンラインショッピングをしています。
商品画像に代替テキストが設定されていないため、どのような商品なのか分かりません。
「image_12345.jpg」と読み上げられても、商品の色やデザインが分からず、購入を諦めることになりました。
</Card>

<Aside type="danger" title="こんなとき、達成されていないかもしれません">
- 画像に`alt`属性が設定されていない
- `alt`属性が空ではなく、ファイル名がそのまま入っている（例：`alt="IMG_001.jpg"`）
- アイコンボタンに代替テキストがなく、機能が分からない
- アイコンの見た目を説明している（例：「バツ印」→「閉じる」とすべき）
- 装飾的な画像に意味のある`alt`テキストが設定されている（逆のケース）
- グラフや図表に詳細な説明がない
</Aside>

## 最低限、すぐに取り組めること

### 要件定義

- 機能要件に「すべての非テキストコンテンツに適切な代替テキストを提供する」を明記する
- 画像を使用する機能では、代替テキストの入力フィールドを必須とする

### デザイン

- 画像やアイコンの目的を明確にし、代替テキストの指示をデザインドキュメントに記載する
- 装飾的な要素と意味のある要素を区別してデザインする

### 開発

- `img`要素には必ず`alt`属性を設定する
- 装飾的な画像には`alt=""`（空のalt）を設定する
- アイコンボタンでは、SVGに`role="img"`と`aria-label`を設定し、ボタンのアクセシブルネームとして扱う
- 装飾用のSVGは`aria-hidden="true"`を設定する

### QA

- スクリーンリーダーで画像やアイコンの読み上げを確認する
- `alt`属性が設定されていない画像がないかチェックする
- 代替テキストが画像の内容を適切に説明しているか確認する

### リリース後

- ユーザーからのフィードバックを収集し、代替テキストの改善に活かす
- 新しいコンテンツを追加する際は、代替テキストの設定を忘れないようにする

## よくある問題と解決方法

### 「画像」や「アイコン」で始まる代替テキスト

<Aside type="danger">
スクリーンリーダーは既に「画像」であることを伝えるため、代替テキストを「画像：」で始める必要はありません。
</Aside>

```html title="悪い例"
<img src="product.jpg" alt="画像：赤いセーター" />
```

```html title="良い例"
<img src="product.jpg" alt="赤いニットセーター Mサイズ" />
```

### 複雑な図表やグラフの説明

複雑な図表には、短い`alt`属性に加えて、詳細な説明を別途提供します。

```html title="詳細な説明を提供する方法"
<figure>
  <img src="sales-chart.png" alt="2024年月別売上グラフ" aria-describedby="chart-desc" />
  <figcaption id="chart-desc">
    1月から12月までの売上推移。1月は100万円からスタートし、
    6月に最高値の500万円を記録。年間平均は300万円。
  </figcaption>
</figure>
```

### 背景画像に意味がある場合

CSSの背景画像には`alt`属性を設定できないため、代替手段を使用します。

```html title="背景画像に代替テキストを提供する方法"
<div
  role="img"
  aria-label="夕焼けの海岸線"
  style="background-image: url('sunset.jpg');">
</div>
```

### リンク画像の代替テキスト

リンク内の画像は、リンク先を説明する代替テキストを設定します。

```html title="リンク画像の適切な代替テキスト"
<a href="/products/sweater">
  <img src="sweater.jpg" alt="赤いニットセーター 商品詳細ページへ" />
</a>
```

### アイコンの見た目ではなく機能を説明する

アイコンボタンの代替テキストには、アイコンの見た目ではなく**機能**を説明します。

<Aside type="danger">
「バツ印」「矢印」などアイコンの見た目を説明するのではなく、「閉じる」「戻る」など機能を説明してください。
</Aside>

```html title="悪い例：見た目を説明している"
<button>
  <svg role="img" aria-label="バツ印">...</svg>
</button>
```

```html title="良い例：機能を説明している"
<button>
  <svg role="img" aria-label="閉じる">...</svg>
</button>
```

### SVGアイコンへの代替テキストの付与方法

アイコンボタンの実装では、**ボタン要素ではなくアイコン自体にアクセシブルな名前を付ける**ことが推奨されます。SVGに付けた`aria-label`はボタンのアクセシブルネームとして反映されます。

<Aside type="note" title="アクセシブルネームとは？">
スクリーンリーダーなどが読み上げる「ボタンの名前」のことです。`aria-label`に入れた文言がそのまま読み上げられます。
</Aside>

```html title="ボタンに付ける方法（非推奨）"
<button aria-label="閉じる">
  <svg aria-hidden="true">...</svg>
</button>
```

```html title="アイコンに付ける方法（推奨）"
<button>
  <svg role="img" aria-label="閉じる">...</svg>
</button>
```

アイコンは装飾ではなく意味を持つ画像です。`img`要素に`alt`属性を付けるのと同様に、SVGアイコンにも`role="img"`と`aria-label`を付けることで、実装の一貫性が保たれます。

代替テキストを付与する方法は他にもあります。

1. **SVGに`role="img"`と`aria-label`を設定する方法** - 主要なブラウザとスクリーンリーダーで安定して動作します
2. **Visually Hiddenテキストを使用する方法** - コンポーネント化すると扱いやすくなります

詳細な比較は「[SVGアイコンボタンにアクセシブルな名前を付ける方法の比較](https://zenn.dev/moneyforward/articles/20231120-icon-button-accessible-name)」を参照してください。

## チェックリスト

<Aside type="caution" title="必須チェック項目">
- [ ] すべての`img`要素に`alt`属性が設定されている
- [ ] 代替テキストが画像の内容や目的を適切に説明している
- [ ] 装飾的な画像には`alt=""`が設定されている
- [ ] アイコンボタンには代替テキスト（`aria-label`など）が設定されている
</Aside>

<Aside type="note" title="推奨項目（中優先度）">
- [ ] 複雑な図表には詳細な説明が提供されている
- [ ] 代替テキストが「画像」「アイコン」で始まっていない
- [ ] リンク画像の代替テキストがリンク先を説明している
</Aside>

## 知っておくと便利なこと

### 代替テキストの種類と使い分け

| 画像の種類 | 代替テキストの設定方法 | 例 |
|-----------|---------------------|---|
| 情報を伝える画像 | 内容を説明する`alt`属性 | `alt="売上グラフ：1月100万、2月150万"` |
| 装飾的な画像 | 空の`alt`属性 | `alt=""` |
| 機能を持つ画像（ボタンなど） | 機能を説明する`alt`または`aria-label` | `aria-label="検索"` |
| 複雑な画像 | 短い`alt` + 詳細な説明 | `alt="組織図" aria-describedby="org-desc"` |

### プラットフォーム別の実装方法

#### Web（HTML）
```html
<img src="image.jpg" alt="説明文" />
```

#### iOS（SwiftUI）
```swift
Image("product")
  .accessibilityLabel("赤いニットセーター")
```

#### Android（Jetpack Compose）
```kotlin
Image(
  painter = painterResource(id = R.drawable.product),
  contentDescription = "赤いニットセーター"
)
```

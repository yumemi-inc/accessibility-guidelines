<Aside type="tip" title="このガイドラインで目指すこと">
視覚的なコントラストを適切に確保することで、弱視や高齢者など、視力に制約のあるユーザーがテキストやUI要素を認識しやすくします。

- 様々な環境（明るい場所や古いディスプレイなど）でもコンテンツを読みやすくする
- 視力に依存せず、すべてのユーザーが情報を取得できる
</Aside>

## このガイドラインが達成されないとどうなるか

<Aside type="caution">
コントラスト比が低いと、弱視のユーザーや高齢者はテキストを読むのに苦労し、情報を取得できなくなります。
</Aside>

結果的に、重要な情報が読み取れず、サービスの利用を断念することになります。

<Card title="具体例：ECサイトでの困りごと" icon="information">
Dさんは軽度の弱視があり、特に薄い色のテキストが読みにくいです。
あるECサイトで商品の価格がグレーの薄い文字で表示されており、何度も目を細めて確認する必要がありました。
結局、疲労のため購入を断念してしまいました。
</Card>

<Aside type="danger" title="こんなとき、達成されていないかもしれません">
- 薄いグレーのテキストを白背景で使用している
- プレースホルダーテキストのコントラストが低い
- 無効状態のボタンのテキストが見えにくい
- 背景画像の上にテキストが乗っていて読みにくい
- デザイン重視で淡い色の組み合わせを使用している
</Aside>

## 最低限、すぐに取り組めること

### 要件定義

- デザインガイドラインに最小コントラスト比の要件を明記する
- 通常テキスト：4.5:1以上
- 大きなテキスト（24px以上、または18.67px以上の太字）：3:1以上

### デザイン

- カラーパレット作成時にコントラスト比を確認する
- 背景色と前景色の組み合わせをドキュメント化する
- プレースホルダーやdisabled状態も基準を満たすようにする

### 開発

- CSSでカラー変数を使用し、一元管理する
- コントラストチェッカーをCI/CDに組み込む
- 背景画像の上にテキストを置く場合は、オーバーレイを使用する

```css title="背景画像上のテキストを読みやすくする方法"
.hero {
  position: relative;
  background-image: url('hero.jpg');
}

.hero::before {
  content: '';
  position: absolute;
  inset: 0;
  background: rgba(0, 0, 0, 0.5); /* 半透明のオーバーレイ */
}

.hero-text {
  position: relative;
  color: white;
}
```

### QA

- コントラストチェッカーで全ページを確認する
- 実際のデバイスで様々な環境（明るい場所、暗い場所）でテストする
- 弱視シミュレーションツールで確認する

### リリース後

- ユーザーからのフィードバックを収集する
- コントラストに関する問題を継続的に改善する

## よくある問題と解決方法

### 背景画像の上にテキストがある

背景画像は場所によって明るさが異なるため、テキストの可読性を低下させることがあります。

#### 解決方法

1. 半透明のオーバーレイを使用する
2. テキストに影を付ける
3. テキスト背景にボックスを追加する

```css title="テキストを読みやすくする方法"
/* 方法1: オーバーレイ */
.hero::before {
  background: linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5));
}

/* 方法2: テキストシャドウ */
.hero-text {
  text-shadow: 0 2px 4px rgba(0, 0, 0, 0.5);
}

/* 方法3: 背景ボックス */
.hero-text {
  background: rgba(0, 0, 0, 0.7);
  padding: 8px 16px;
}
```

### ダークモード対応

ダークモードでもコントラスト比を維持する必要があります。

```css title="ダークモードでのコントラスト確保"
:root {
  --text-primary: #333;     /* 白背景で12.6:1 */
  --text-secondary: #767676; /* 白背景で4.5:1 */
  --bg-primary: #fff;
}

@media (prefers-color-scheme: dark) {
  :root {
    --text-primary: #f0f0f0;  /* 黒背景で15:1 */
    --text-secondary: #b0b0b0; /* 黒背景で7:1 */
    --bg-primary: #1a1a1a;
  }
}
```

## チェックリスト

<Aside type="caution" title="必須チェック項目">
- [ ] 通常のテキスト（24px未満）が背景色に対して4.5:1以上のコントラスト比を満たしている
- [ ] 大きなテキスト（24px以上、または18.67px以上の太字）が3:1以上のコントラスト比を満たしている
- [ ] プレースホルダーテキストが4.5:1以上のコントラスト比を満たしている
</Aside>

<Aside type="note" title="推奨項目（中優先度）">
- [ ] UI要素（ボタン、入力フィールドの境界線など）が3:1以上のコントラスト比を満たしている
- [ ] 無効状態の要素も最低限の視認性が確保されている
- [ ] ダークモードでもコントラスト比が維持されている
</Aside>

## 知っておくと便利なこと

### コントラスト比の基準

| テキストの種類 | 最小コントラスト比（AA） | 推奨コントラスト比（AAA） |
|--------------|---------------------|----------------------|
| 通常テキスト（24px未満） | 4.5:1 | 7:1 |
| 大きなテキスト（24px以上） | 3:1 | 4.5:1 |
| 太字テキスト（18.67px以上） | 3:1 | 4.5:1 |

<Aside type="note" title="テキストサイズの単位について">
WCAGではテキストサイズの要件をpt単位（18pt/14pt）で定めています。これをpx単位に換算すると約24px/18.67pxに相当します。
ptは印刷用の単位で、pxは画面上のピクセル単位です。デバイスの解像度によって実際の表示サイズが異なるため、px単位での指定の場合は注意が必要です。
</Aside>

### コントラスト比の計算ツール

- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) - Webベースのコントラストチェッカー
- Chrome DevTools: 要素の色をホバーするとコントラスト比が表示される
- Figma: プラグイン「Contrast」「Stark」などで確認可能

### よく使われる安全な色の組み合わせ

```css title="コントラスト比を満たす色の組み合わせ"
/* 白背景での使用 */
--text-on-white-primary: #333;   /* 12.6:1 */
--text-on-white-secondary: #555; /* 7.5:1 */
--text-on-white-minimum: #767676; /* 4.5:1 */

/* 黒背景での使用 */
--text-on-black-primary: #fff;   /* 21:1 */
--text-on-black-secondary: #ccc; /* 13.1:1 */
--text-on-black-minimum: #949494; /* 4.5:1 */
```

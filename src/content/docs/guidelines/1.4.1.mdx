<Aside type="tip" title="このガイドラインで目指すこと">
色覚特性の違いや、モノクロ表示などの環境においても、情報の伝達や操作の実行が可能であることを保証します。

- 色が見えない・区別できない環境でも情報が伝わる
- 誰もが確実に情報を受け取れるようにする
</Aside>

## このガイドラインが達成されないとどうなるか

<Aside type="caution">
色のみで情報を伝えると、色覚特性の違いを持つ約320万人の日本人や、モノクロプリンタで印刷した人が情報を理解できません。
</Aside>

結果的に、重要な情報の見落としや誤操作が発生し、サービスの利用に支障をきたします。

<Card title="具体例：フォーム送信での困りごと" icon="information">
Cさんは重要な申請フォームを入力していました。
必須項目が赤色のみで示されていたため、色覚特性により見分けがつかず、必須項目を見落として送信。
エラーが出ましたが、どの項目がエラーなのかも赤色のみで示されており、結局申請期限に間に合いませんでした。
</Card>

<Aside type="danger" title="こんなとき、達成されていないかもしれません">
- 必須項目を赤文字のみで表示している
- グラフの凡例が色のみで区別されている
- エラーメッセージが赤色になるだけで、アイコンやテキストがない
- リンクが色の変化のみで、下線がない
- ステータス表示が「緑=OK」「赤=NG」の色のみ
</Aside>

## 最低限、すぐに取り組めること

### 要件定義

- 機能要件に「色のみで情報を伝えない」を明記する
- 色覚多様性を考慮した設計方針を定める

### デザイン

- 必須項目には「必須」ラベルを付ける
- エラー・警告・成功にはアイコンを併用する
- グラフにはパターンやラベルを追加する

### 開発

- フォームバリデーションにテキストメッセージを含める
- ステータス表示にアイコンやテキストを追加する
- リンクには下線やアイコンを付ける

### QA

- モノクロ表示で情報が伝わるか確認する
- 色覚シミュレーターでテストする
- スクリーンリーダーで情報が伝わるか確認する

### リリース後

- ユーザーフィードバックを収集する
- アクセシビリティ監査を定期実施する

## よくある問題と解決方法

### デザインの制約があると言われた場合

#### 段階的な改善アプローチ

1. **最小限の対応**：テキストラベルを追加
2. **次のステップ**：アイコンを併用
3. **理想的な対応**：パターンや形状も活用

### 既存システムの改修が難しい場合

```css title="CSSのみで最小限の改善"
/* 必須項目に * を追加 */
.required::after {
  content: " *";
  color: #dc2626;
  font-weight: bold;
}

/* リンクに下線を追加 */
a {
  text-decoration: underline !important;
}

/* エラーメッセージにアイコンを追加 */
.error::before {
  content: "⚠ ";
  font-size: 1.2em;
}
```

## チェックリスト

### 必ず対応（高優先度）

<Aside type="caution" title="必須チェック項目">
- [ ] **必須項目**がテキストやマークで示されている
- [ ] **エラーメッセージ**にテキスト説明がある
- [ ] **リンク**が下線などで識別可能
</Aside>

<Aside type="note" title="推奨項目（中優先度）">
- [ ] **ステータス表示**にアイコンやテキストがある
- [ ] **グラフ**にパターンやラベルがある
- [ ] **警告・成功**メッセージにアイコンがある
</Aside>

### 関連項目（別ガイドライン対象）

- [ ] **コントラスト比**が適切である（1.4.3）
- [ ] **フォーカス表示**が見やすい（2.4.7）

## 知っておくと便利なこと

### 色覚特性の種類と見え方

| タイプ | 割合 | 特徴 |
|-------|------|------|
| P型（1型） | 男性の約1.5% | 赤の感度が低い |
| D型（2型） | 男性の約3.5% | 緑の感度が低い |
| T型（3型） | 約0.001% | 青の感度が低い |

<Aside type="tip" title="ユニバーサルデザインカラー">
以下の色の組み合わせは比較的区別しやすいとされています：

- 青とオレンジ
- 青と黄色
- 紫と緑黄色

避けるべき組み合わせ：
- 赤と緑
- 黄緑と黄色
- 青と紫
</Aside>

<Aside type="tip" title="このガイドラインで目指すこと">
視覚的な情報に依存できないユーザー（スクリーンリーダー利用者など）が、画像やアイコンなどの非テキストコンテンツの内容や目的を理解できるようにします。

- すべてのユーザーが同等の情報へアクセスできる
- 画像が表示されない環境でも内容を理解できる
</Aside>

## このガイドラインが達成されないとどうなるか

<Aside type="caution">
代替テキストがないと、スクリーンリーダー利用者は画像の内容を理解できず、重要な情報を見逃してしまいます。
</Aside>

結果的に、サービスの利用に支障をきたし、「見える人」と「見えない人」で情報格差が生じます。

<Card title="具体例：ECサイトでの困りごと" icon="information">
Bさんはスクリーンリーダーを使用してオンラインショッピングを楽しんでいます。
しかし、商品画像に代替テキストがないサイトでは、商品の色や形状が分からずに購入判断ができません。
結果的に、そのサイトの利用を諦めて他のサイトで買い物をするようになりました。
</Card>

<Aside type="danger" title="こんなとき、達成されていないかもしれません">
- 画像に`alt`属性が設定されていない
- アイコンボタンに何の説明もない（「ボタン」としか読み上げられない）
- 装飾画像にも長い説明文が入っている（読み上げが冗長になる）
- 「image001.jpg」のようなファイル名が代替テキストになっている
</Aside>

## 最低限、すぐに取り組めること

### 要件定義

- 機能要件に「すべての画像、アイコンに代替テキストを提供する」を明記する
- 装飾的な画像と情報を伝える画像の判断基準を定義する

### デザイン

- 画像やアイコンを配置する際、その説明文も一緒に定義する
- アイコンボタンにはツールチップやラベルの表示を検討する

### 開発

- 画像には必ず`alt`属性を設定する
- アイコンボタンには`aria-label`を設定する
- 装飾画像には`alt=""`を設定する

<Card title="最小限の実装例" icon="approve-check">

<LiveCodeExample
  html={dedent`
    <!-- 情報を伝える画像 -->
    <img src="product.jpg" alt="赤いTシャツ、サイズM">

    <!-- 装飾的な画像 -->
    <img src="decoration.jpg" alt="" role="presentation">

    <!-- アイコンボタン -->
    <button aria-label="メニューを開く">
      <svg aria-hidden="true"><!-- アイコン --></svg>
    </button>

    <!-- テキスト付きアイコン -->
    <button>
      <svg aria-hidden="true"><!-- アイコン --></svg>
      <span>保存</span>
    </button>
  `}
  css={dedent`
    button {
      padding: 8px 16px;
      margin: 8px;
      border: 1px solid #ccc;
      border-radius: 4px;
      background: white;
      cursor: pointer;
      display: inline-flex;
      align-items: center;
      gap: 8px;
    }

    button:focus-visible {
      outline: 2px solid #005fcc;
      outline-offset: 2px;
    }

    img {
      max-width: 100%;
      height: auto;
    }
  `}
  client:load
/>

</Card>

### QA

- スクリーンリーダーで全画像・アイコンを確認する
- 画像を非表示にしてもページの意味が通じるか確認する

- ユーザーからのフィードバックを収集する
- 代替テキストの質を継続的に改善する

## よくある問題と解決方法

### 代替テキストに何を書けばいいか分からない

#### 判断フローチャート

1. **装飾的な画像かどうか**
   - Yes → `alt=""`
   - No → 次へ

2. **リンクやボタンの一部かどうか**
   - Yes → リンク先や機能を説明
   - No → 次へ

3. **テキストが含まれる画像かどうか**
   - Yes → そのテキストを代替テキストに
   - No → 画像の内容を簡潔に説明

### 背景画像の場合

CSSの背景画像は装飾的なものとして扱われるため、情報を伝える画像には使用しないようにします。

```css title="情報を伝える画像はHTMLで実装"
/* 悪い例：情報をCSS背景画像で表示 */
.hero {
  background-image: url('important-info.jpg');
}

/* 良い例：装飾的な背景のみCSS */
.decorative {
  background-image: url('pattern.svg');
}
```

## チェックリスト

### 必ず対応（高優先度）

<Aside type="caution" title="必須チェック項目">
- [ ] **すべての画像**に`alt`属性が設定されている
- [ ] **アイコンボタン**に`aria-label`が設定されている
- [ ] **装飾画像**は`alt=""`になっている
</Aside>

<Aside type="note" title="推奨項目（中優先度）">
- [ ] **複雑な図表**に詳細な説明がある
- [ ] **代替テキスト**が簡潔で分かりやすい
- [ ] **文脈を考慮**した説明になっている
</Aside>

### 関連項目（別ガイドライン対象）

- [ ] **動画**に字幕や音声解説がある
- [ ] **音声コンテンツ**に文字起こしがある

## 知っておくと便利なこと

### プラットフォーム別の実装方法

| プラットフォーム | 実装方法 | 例 |
|--------------|---------|-----|
| HTML | `alt`属性、`aria-label` | `<img alt="説明">` |
| iOS | `accessibilityLabel` | `image.accessibilityLabel = "説明"` |
| Android | `contentDescription` | `android:contentDescription="説明"` |
| React Native | `accessibilityLabel` | `accessibilityLabel="説明"` |

<Aside type="tip" title="AIを活用した代替テキスト生成">
最近のAIツールは画像の内容を説明できますが、必ず人間が確認・修正しましょう。

- 文脈に合っているか
- 重要な情報が含まれているか
- 簡潔で分かりやすいか
</Aside>
